# 🛒 Loja de Suplementos

E-commerce de suplementos desenvolvido com **Django** e **PostgreSQL**, utilizando **Docker** para garantir um ambiente isolado e pronto para produção.

### 🔗 Link da Demonstração
Acesse a loja online: [https://jill-unchastened-stewart.ngrok-free.dev](https://jill-unchastened-stewart.ngrok-free.dev)

---

### 🛠️ Tecnologias Principais
* **Framework:** Django (Python)
* **Banco de Dados:** PostgreSQL
* **Infraestrutura:** Docker & Docker Compose
* **Pagamentos:** API do Mercado Pago
* **Hospedagem:** AWS (Amazon Web Services)
